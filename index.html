Bring the animation into Roblox Studio

  1. Export ▸ Rig + animation (.rbxmx) downloads an R15 rig with the animation saved inside it.
  2. In Studio, right-click Workspace in the Explorer ▸ Insert from File… and pick the file (or drag the file onto the viewport).
  3. Open Avatar ▸ Animation Editor, click the rig, then in the editor's ⋯ menu choose Load and pick your animation.
  4. Every keyframe is now editable — move joints, delete keys, change easing — then Publish to Roblox to get an Animation ID.

Using your own avatar or rig instead

Download the Command Bar script, select your R15 model in Studio, open View ▸ Command Bar, paste the script and press Enter. The animation is added to that model's AnimSaves (or a fresh rig is created if nothing is selected). You can also insert the KeyframeSequence only file and drag it into your rig's AnimSaves.

Getting the most accurate result

  • One person, whole body visible (feet included), camera on a tripod, good light.
  • Facing the camera or at an angle works best; pure side views lose depth.
  • Use the Heavy model. Check the red parts of the timeline — those frames were guessed.
  • Fix leftovers in Joints (per-joint offsets) or later in the Animation Editor.
